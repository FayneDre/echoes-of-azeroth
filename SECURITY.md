# Security policy

Echoes of Azeroth downloads and runs server software on players' machines, so
we take integrity seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private
[security advisory form](https://github.com/FayneDre/echoes-of-azeroth/security/advisories/new).
We aim to acknowledge reports within 7 days.

## Scope

- The launcher (`app/`, `crates/`), the catalog and its signing, CI release workflows.
- Out of scope: vulnerabilities in upstream emulators or modules (report them
  upstream; we will update pins once fixed).

## Design commitments

- Artifacts are verified (signed index + per-file hashes) before execution.
- MySQL and SOAP listen on `127.0.0.1` only; LAN mode exposes only auth/world ports.
- Credentials generated by the launcher are stored with Windows DPAPI.
- Release binaries are built and signed by CI only.
